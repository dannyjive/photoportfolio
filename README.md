# React Photo Portfolio

A responsive photo portfolio built with **React**, **React-Bootstrap**, **Masonry layout**, and **React Context**.  
Designed to showcase photography in a clean, modern grid with global state management and smooth responsiveness across devices.

## 🚀 Live Demo
Example: https://dan-finley.com/photo

## 📸 Features

- Responsive masonry-style image layout
- Global state management using React Context
- Clean, minimal UI built with React-Bootstrap
- Optimized for desktop, tablet, and mobile
- Component-based architecture for scalability
- Lightbox / modal image viewer
- Category filtering
- Lazy loading for images
- Animation enhancements with GSAP

## 🛠️ Built With

- **React**
- **React-Bootstrap**
- **Masonry Layout**
- **React Context API**
- **CSS / Bootstrap Utilities**

## 🧠 What I Practiced

- Managing shared state with Context instead of prop drilling
- Integrating third-party layout libraries into React
- Structuring reusable components for galleries and UI
- Responsive design using Bootstrap’s grid system
- Organizing assets and data for a real-world portfolio
